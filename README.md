# Nexus Programming Language

Nexus is a fast, strongly typed general purpose programming language built from scratch in JavaScript.

## Features
- Variables and constants
- Math operations  
- Functions with return values
- if/else statements
- While loops
- Built-in print() function
- Run .nx files from command line
- Interactive REPL

## Usage
Run a file:
node nexus.js yourfile.nx

Start the REPL:
node repl.js

## Example
let x = 10;
let y = 20;
print(x + y);
